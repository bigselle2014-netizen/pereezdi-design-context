# Переезды · материалы для дизайна

Сайт переездов и перевозок по Москве и Московской области. Материалы собраны для передачи дизайнеру или агенту.

1. [Аудитория](docs/AUDIENCE.md) и [выдержки с источниками](docs/research/2026-11-04/audience-selection.json) — что влияет на решение заказчика. Это качественные наблюдения из прежнего исследования.
2. [Бриф](docs/BRIEF.md), [позиционирование](docs/POSITIONING.md) и [первый выпуск](docs/FIRST-RELEASE.md) — продукт, границы услуг и обещаний.
3. [Прототип главной](docs/prototypes/HOME.md) и [тексты блоков](docs/prototypes/HOME.txt) — содержание и сценарий запроса расчёта.
4. [Коммерческие факторы](docs/COMMERCIAL-FACTORS.md), [референсы](docs/design/REFS.md) и [наблюдения по нише](docs/design/NICHE.md) — примеры с рынка. Цены и обещания конкурентов не относятся к проекту.

Сценарий главной: выбор услуги → состав сметы → сохранность и подача → описание заказа для оценки. Для тарифов, гарантий, сроков и отзывов нужны подтверждённые данные бизнеса.
