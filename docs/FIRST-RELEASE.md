# Переезды и перевозки Москвы и МО — принятый состав первого выпуска

05.11.2026 · Корень: `pereezdi`. Цель: покупатель узнаёт свой сценарий, понимает, какие данные нужны для оценки, и может обратиться. Принятый состав: **13 страниц из 34 в реестре, включая главную и один маршрутизатор**, плюс 6 служебных адресов по мере готовности данных. Все URL проектные. Согласование состава, полнота семантики и готовность к публикации — разные решения.

Входы: план, реестр, выводы конкурентного анализа, раздельные адреса конкурентов, принятые срезы Яндекса, покрытие семантики. Числа в скобках — строки текущих проектных назначений, а не частоты спроса.

## Проверка и решение по спорным страницам

Сверил три вещи: отличается ли сам заказ, есть ли для него отдельные страницы в сохранённых выдачах и что покупатель получит на этой странице. Затем прошёл по меню с конкретными заказами.

| Заказ покупателя | Куда ведём | Решение |
|---|---|---|
| «Съезжаем из коттеджа, везём всё» / «Везём несколько вещей на дачу» | Дом и коттедж / Дача | **Оставить две страницы.** Разный состав заказа, в принятых десятках нет общих адресов между сценариями. Для дома ещё проверить новые формулировки. |
| «Перевозим стеллажи и весь склад» / «Закрываем магазин на выходные и переезжаем» | Склад / Магазин | **Оставить две страницы.** На складе важна очерёдность переноса, в магазине — возобновление работы точки. У 12 конкурентов отдельные адреса. Спрос по узким формулировкам ещё уточнить. |
| «Смена офиса» / «Отвезти три офисных стола» | Офис / Мебель | **Оставить раздельно.** В первом заказе согласуют перенос рабочих мест и простой, во втором нужны габариты, доступ и защита мебели. |
| «Машина есть, нужно разгрузить» / «Нужна машина с водителем» | Только грузчики / Машина с водителем | **Оставить две страницы.** В первом заказе покупают работу людей, во втором — транспорт. У грузчиков один пункт меню в «Перевозках», со страниц переездов ведёт ссылка из описания работ. |
| «Купил холодильник с рук, нужно отвезти» | Перевозки → Холодильник | **Оставить страницу.** Нужно проверить модель, размеры, путь выноса и допустимое положение. Сохранённый коммерческий маркер относится к Москве, общий запрос смешан с инструкциями. |

Отдельная страница получит смысл, если обнаружится отдельный заказ со своим процессом, например с передачей по документам или окнами приёмки. Смешанные фразы остаются на проверке. |

**Решение по составу: 13 страниц.** Страница «Другой объект» нужна, чтобы подать заявку на переезд бизнеса, которого нет в меню. Для неё в реестре 0 поисковых назначений. Самые открытые вопросы по поиску — полнота группы дома и граница местной доставки. Они требуют адресного добора в Яндексе перед окончательной фиксацией поисковых назначений. Проверка меню выполнена по сценариям в документе. Удобство меню на экране можно проверить после прототипа.

## Состояние поисковой проверки

Адресный добор в Яндексе и Вордстате проверил новые формулировки по дому, складу, магазину, холодильнику, офису, грузчикам, машине, вещам и мебели. Выдачи поддержали раздельные маршруты. Для дома, склада и магазина пригодные частоты по новым формулировкам не получены. Новые пробные формулировки в реестр не добавлены. Вывод по местной доставке прежний: развоз по точкам доступен через описание задачи; отдельная страница пока в резерве.

Старые seed и принятые проверки не повторялись. Google отложен. Состав из 13 страниц принят. Назначения уточняются; разработка ещё не начата.
